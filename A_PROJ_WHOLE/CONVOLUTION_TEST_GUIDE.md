# 卷积功能快速测试指南

## 测试前准备

### 硬件连接
1. FPGA板连接到PC
2. USB转串口连接到FPGA的UART接口
3. 确认波特率设置为 **115200**

### 软件准备
1. 串口助手（推荐：sscom、PuTTY等）
2. 配置：115200, 8N1, 无流控

## 测试步骤

### Step 1: 进入卷积模式
```
操作：
1. SW[7:5] = 100  (Operator模式)
2. SW[2:0] = 100  (卷积操作J)
3. 按 btn_confirm (确认键)

预期结果：
- DK1 显示 'O' (Operator)
- DK4 显示 'J' (卷积)
- LED_BUSY 可能闪烁（等待输入）
```

### Step 2: 发送卷积核（通过串口）
```
操作：
使用串口助手发送9个字节的十六进制数据

示例1 - 边缘检测卷积核:
发送: 01 00 01 00 00 00 01 00 01
矩阵形式:
[ 1  0  1 ]
[ 0  0  0 ]
[ 1  0  1 ]

示例2 - 均值模糊卷积核:
发送: 01 01 01 01 01 01 01 01 01
矩阵形式:
[ 1  1  1 ]
[ 1  1  1 ]
[ 1  1  1 ]

示例3 - 锐化卷积核:
发送: 00 01 00 01 04 01 00 01 00
矩阵形式:
[ 0  1  0 ]
[ 1  4  1 ]
[ 0  1  0 ]

注意：
- 每个字节取低4位作为卷积核元素
- 建议发送0-9的值
- 按行优先顺序发送（从左到右，从上到下）
```

### Step 3: 启动计算
```
操作：
1. 确认已发送完9个字节
2. 按 btn_confirm (确认键)

预期结果：
- LED_BUSY 立即亮起
- 系统开始统计时钟周期
- 卷积计算进行中
```

### Step 4: 查看结果

#### a) 串口输出（自动）
```
计算完成后，串口自动输出8x10矩阵：

格式示例：
012 034 056 078 090 012 034 056 078 090
023 045 067 089 001 023 045 067 089 001
034 056 078 090 012 034 056 078 090 012
...（共8行，每行10个数据）

C: 0234  <-- 时钟周期数

说明：
- 每个数字占3位（不足3位前补0）
- 数字之间用空格分隔
- 每10个数字换行
- 最后一行显示总周期数
```

#### b) 数码管显示
```
DK7 和 DK8 显示时钟周期数：

情况1: 周期数 < 100
- DK7 显示十位
- DK8 显示个位
示例：45周期 -> DK7='4', DK8='5'

情况2: 周期数 >= 100
- DK7 显示百位
- DK8 显示十位
示例：234周期 -> DK7='2', DK8='3'

注意：实际周期数以串口输出为准
```

#### c) LED指示
```
- LED_BUSY 熄灭
- LED_DONE 亮起
- 表示计算完成
```

## 预期性能

### 时钟周期估算
```
输入图像: 10x12 = 120 像素
输出图像: 8x10 = 80 像素
每个输出像素需要: 3x3 = 9次乘加
每次乘加约需: 3-5个时钟周期

预估总周期: 80 × 9 × 4 ≈ 2880 周期
实际值可能因状态机开销略有增加
```

## 故障排查

### 问题1：串口无输出
```
检查项：
1. 波特率是否为115200
2. UART TX/RX线是否正确连接
3. 是否发送了完整的9个字节
4. 是否按了确认键启动计算
```

### 问题2：数码管显示异常
```
检查项：
1. 是否已完成计算（LED_DONE亮起）
2. 是否在S_OP_J状态
3. 周期数是否超过999（显示不完整）
```

### 问题3：计算未启动
```
检查项：
1. 确认已进入S_OP_J状态
2. 确认已通过串口发送9个字节
3. 确认按了确认键
4. 检查rst_n信号是否有效
```

### 问题4：结果不正确
```
检查项：
1. 确认卷积核输入顺序（行优先）
2. 查看串口输出确认输入图像ROM数据
3. 手工计算几个点验证算法
4. 检查数据溢出（16位结果范围）
```

## 调试建议

### 使用ILA观察
```
建议添加ILA观察以下信号：
- conv_kernel_packed[35:0]  卷积核数据
- conv_start_pulse          启动信号
- conv_pixel_valid          结果有效
- conv_done                 完成标志
- conv_cycle_count[15:0]    周期计数
```

### 仿真测试
```
建议先进行仿真测试：
1. 创建testbench模拟UART输入
2. 验证卷积核接收正确
3. 验证周期计数准确
4. 验证输出矩阵正确
```

## 扩展功能建议

1. **支持更多卷积核尺寸**：修改为5x5或7x7
2. **支持不同步长**：添加stride参数
3. **支持padding**：添加边缘填充选项
4. **优化性能**：使用流水线或并行计算
5. **存储结果**：将结果写入矩阵存储单元
