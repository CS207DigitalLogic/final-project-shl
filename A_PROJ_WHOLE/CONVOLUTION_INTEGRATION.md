# 卷积模块集成说明

## ✅ 已完成的集成工作

### 1. 文件创建
已在 `A_PROJ_WHOLE/design/calculation/` 中创建以下文件：
- `convolution.sv` - 卷积计算核心模块
- `input_image_rom.v` - 图像ROM存储（10x12图像数据）
- `convolution_controller.v` - 卷积控制器（UART输入/输出、周期计数）

### 2. integrated_top.v 修改

#### 添加的模块实例：
```verilog
// 卷积控制器（处理UART输入卷积核、计数、输出结果）
convolution_controller u_conv_ctrl (...)

// 卷积计算模块
convolution u_convolution (...)
```

#### 功能特性：
1. **UART输入卷积核**：通过串口接收3x3=9个字节的卷积核数据
2. **时钟周期统计**：自动统计卷积计算耗时
3. **UART输出结果**：串口输出8x10结果矩阵
4. **数码管显示周期数**：在DK7/DK8显示时钟周期数

## 📋 使用方法（符合项目要求）

### 完整操作流程：

#### 1. 进入卷积模式
- 将 SW[7:5] 设置为 `100` 进入Operator模式
- 将 SW[2:0] 设置为 `100` 选择卷积操作（J）
- 数码管DK1显示 'O'，DK4显示 'J'

#### 2. 输入卷积核（通过UART）
系统会自动开始等待UART输入。通过串口助手发送9个字节：
```
示例卷积核（边缘检测）:
发送: 0x01 0x00 0x01 0x00 0x00 0x00 0x01 0x00 0x01
对应矩阵:
[ 1  0  1 ]
[ 0  0  0 ]
[ 1  0  1 ]
```

每个字节的低4位将作为卷积核元素（0-9的值）。

#### 3. 启动计算
- 发送完9个字节后，系统自动准备就绪
- **按确认键立即开始计算**
- 此时开始统计时钟周期数
- LED_BUSY 灯亮起

#### 4. 查看结果

**a) 串口显示输出矩阵**
计算完成后，系统自动通过UART发送8x10结果矩阵：
```
格式：每个结果占3位十进制数+空格，每10个换行
示例输出：
012 034 056 078 ...（第1行）
023 045 067 089 ...（第2行）
...
（共8行）
```

**b) 数码管显示总时钟周期数**
- DK7和DK8显示时钟周期数
- 显示范围：0-999周期
- 如果超过99周期，DK7显示百位，DK8显示十位

#### 5. 完成
- LED_DONE 灯亮起
- 可按确认键返回或重新开始

## 📊 测试数据

### 输入图像（10x12，硬编码在ROM中）：
```
第1行: 3 7 2 9 0 5 1 8 4 6 3 2
第2行: 8 1 6 4 7 3 9 0 5 2 8 1
第3行: 4 9 0 2 6 8 3 5 7 1 4 9
...（共10行）
```

### 输出尺寸：
- 输入：10x12 矩阵
- 卷积核：3x3 矩阵
- 步长：1
- **输出：8x10 矩阵**（符合项目要求）

计算公式：
- 输出行数 = 10 - 3 + 1 = 8
- 输出列数 = 12 - 3 + 1 = 10

## 🔧 技术细节

### 时钟周期统计
- 从启动卷积计算开始计数
- 到卷积完成（conv_done信号）停止
- 精确记录整个计算过程耗时

### UART通信格式
**输入格式：**
- 9个连续字节，无需特殊分隔符
- 每个字节低4位有效（0-15）
- 建议发送0-9的值

**输出格式：**
- ASCII文本格式
- 每个结果3位数字 + 1空格
- 每行10个数据后换行
- 最后输出"C: xxxx"表示周期数

### 数码管显示
- 卷积计算时：显示倒计时或状态
- 卷积完成后：显示时钟周期数
  - 0-99：DK7显示十位，DK8显示个位
  - 100-999：DK7显示百位，DK8显示十位

## ⚠️ 注意事项

1. **ROM数据固定**：输入图像硬编码在`input_image_rom.v`中
2. **卷积核动态输入**：通过UART实时输入，无需重新综合
3. **时序要求**：确保UART波特率为115200
4. **结果缓存**：控制器内部缓存80个结果后统一输出
5. **周期计数范围**：支持0-65535周期（16位计数器）
