### lyx

#### 顶层模块

1. 任意状态之间均可切换，切换需按**confirm**。七位数码管显示所在状态。reset回到menu

2. ⚠️INPUTER模式下，使用uart每发送一条数据（如“2 3 1 2 3 4 5 6”），需按**confirm**后再发送新的数据

3. ⚠️GENERATOR模式下，使用uart每发送一条数据（如“2 3 2”），需按**confirm**后再发送新的数据。必须有行数，列数，生成的矩阵数量三个信息，否则发送后，按**confirm**报错灯亮。其余的错误检测都是发送后报错灯就会亮。现有同规格矩阵数量 + 想生成的数量 <= 设置的同规格矩阵数量上限，否则报错。其余报错逻辑同INPUTER

4. DISPLAYER模式下,sw_right[0] = 1 展示摘要信息（如“3 1*2*1 3*3*2”），sw_right[1] = 1 展示所有矩阵

5. SETTING_n 模式下，用sw_left[7:5]选择每规格矩阵数量上限

6. 目前总共可存储15个矩阵，每种规格矩阵数量上限可调整范围为1-7

7. 若led_error（F6）点亮，需按**confirm**才能熄灭

8. 左侧大开关现用于具体数字输入，右侧小开关用于状态转换

9. 运算数选择阶段，sw_left[5:3]选行数，sw_left[2:0]选列数。都拨好后按confirm，再sw_left[2:0]选目标矩阵，按confirm

#### 运算板块倒计时逻辑

1. 倒计时超时，未完成重选运算数：清除所有选择状态，强制回到运算数选择起始阶段

2. 离开运算子状态：清除所有标志

3. 倒计时内选好运算数，不合法：倒计时重置

4. 倒计时内选好运算数，合法：倒计时中或倒计时结束，按**confirm**计算

#### 运算板块操作指南

##### 系统选运算数流程

1. 进入运算子状态（如S_OP_A加法）后，按**confirm**，busy灯（G3）亮，系统自动打印矩阵摘要

2. 拨动 sw_right[3]=1 并按 **confirm** ，系统自动选择合法运算数。乘法找维度匹配，加法优先维度匹配

3. 系统自动选择成功后，通过UART依次显示运算数（如A矩阵，然后B矩阵）

4. 如果系统无法找到合法运算数，报错灯亮，按**confirm**清除后可重试

5. sw_right[3]=0 按**confirm**则进入手动选择模式

##### 人工选运算数流程

1. 进入运算子状态（如S_OP_A加法）后，按**confirm**，busy灯（G3）亮，系统自动打印矩阵摘要

2. 按**S0**开始选维度。sw_left[5:3]选行数，sw_left[2:0]选列数。都拨好后按**confirm**，再sw_left[2:0]选目标矩阵，按**confirm**

3. 若为标量乘法，则完成一次步骤2后，拨动sw_right[7:4]选标量，按**confirm**开始运算

4. 乘法和加法存在维度不匹配。若不匹配，选完第二个运算数后按**confirm**，倒计时开始，报错灯亮。在倒计时内完成新的两个运算数的指定。等倒计时结束后按**confirm**即可计算
